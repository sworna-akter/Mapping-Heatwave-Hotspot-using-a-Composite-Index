# Methodology

This study developed a composite Heatwave Vulnerability Index (HVI) to assess spatial variations in heatwave vulnerability across all 64 districts of Bangladesh.

### HVI Development

The index was constructed using three components:

- **Exposure:** Land Surface Temperature and population density.
- **Sensitivity:** Demographic and socioeconomic indicators.
- **Adaptive Capacity:** Vegetation cover, surface water, and nighttime light indicators.

All indicators were standardised using Min–Max normalisation and aggregated into a composite index:

**HVI = Exposure Index + Sensitivity Index − Adaptive Capacity Index**

### Spatial and Statistical Analysis

The study applied the following methods:

- District-level mapping using GIS and LGED administrative boundaries.
- Anselin Local Moran’s I for cluster and outlier analysis.
- Getis-Ord Gi* for hotspot and coldspot identification.
- Geographically Weighted Regression (GWR) to examine spatial variations in the relationships between HVI and its component indices.
- Sensitivity analysis using four alternative weighting scenarios.
- Monte Carlo simulation (2,000 iterations) to assess uncertainty in HVI estimates and district rankings.

These methods were used to examine the spatial distribution, influencing factors, robustness, and uncertainty of heatwave vulnerability across Bangladesh.
